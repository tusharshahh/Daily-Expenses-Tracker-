# Daily Expenses Summary

A simple **Excel-based Expense Tracker and Daily Expense Summary** designed to record, categorize, and analyze daily spending.

### 📌 Project Overview

This project helps track expenses across different categories such as **Food, Fun, Office, and Investment**. It uses Excel formulas to automatically calculate category-wise expenses and the total amount spent during the day.

### ✨ Key Features

* Daily expense tracking
* Expense categorization
* Category-wise expense calculation
* Automatic total expense calculation
* Percentage-based expense analysis
* Excel formulas using `COUNTIF` and `SUM`
* Simple and easy-to-use expense management structure

### 📊 Expense Categories

* 🍔 Food
* 🎉 Fun
* 🏢 Office
* 📈 Investment

### 🛠️ Tools & Technologies

* Microsoft Excel
* Excel Formulas
* Data Organization & Analysis

### 🎯 Purpose

The project demonstrates practical skills in **Excel, data management, expense tracking, formula-based analysis, and basic financial reporting**.
